# MISSION

**Goal:** Build and verify the TubePreamp plugin, an emulation of a tube microphone preamplifier with console EQ curves (SSL 4000, Neve 1073, Focusrite ISA), and plan for its future extension.

**Objectives:**
1. Ensure the project structure is standard and cleanly initialized.
2. Build the plugin natively for macOS (AU and VST3 formats) using the existing CMake and JUCE configuration.
3. Establish a baseline for current DSP and GUI implementation.
4. Prepare for subsequent enhancements (e.g., Oversampling, Custom GUI, Output Gain, Analyzer, AAX).
