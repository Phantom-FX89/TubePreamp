# Credit Saver Workflow

> **Goal:** Preserve Antigravity credits for high-value work by offloading simple tasks to free AI tools.

---

## Quick Reference: Where to Send Each Task

| Task Type | Send To | Why |
|-----------|---------|-----|
| "Explain this concept" | ChatGPT / Gemini | Free, infinite |
| "What does this error mean?" | Google AI Studio | Fast, free |
| "Review this code snippet" | AI Studio / ChatGPT | No file access needed |
| "Brainstorm ideas" | Any free tier | Creativity doesn't need tools |
| "Write a draft" | ChatGPT | Good at prose |
| "Research a library/API" | Gemini | Great at docs |
| "Summarize this article" | Gemini / ChatGPT | Copy-paste works |

---

## When to Use Antigravity (Worth the Credits)

| Task Type | Why Here |
|-----------|----------|
| Multi-file refactoring | Direct file system access |
| Project scaffolding | Creates entire structure |
| Running tests/commands | Executes on your system |
| Complex debugging | Sees files + runs code |
| Docker/deployment | Orchestrates everything |
| Research + immediate implementation | Search → Build in one flow |
| Large context work | 200K+ token window |

## Daily Workflow

```
1. QUESTION/RESEARCH → Free tool first
   - Open AI Studio or ChatGPT tab
   - Ask there, get answer, done

2. NEED EXPLANATION → Free tool
   - Copy snippet → Paste in free AI
   - Get explanation without burning credits

3. READY TO BUILD → Antigravity
   - Multiple files to change
   - Need commands run
   - Want end-to-end execution

4. COMPLEX ORCHESTRATION → Definitely Antigravity
   - Docker, CI/CD, multi-step builds
   - This is what credits are FOR
```

---

## Before Opening Antigravity, Ask:

> "Can I get this answer by pasting into a free AI?"

- **YES** → Use free tool, save credits
- **NO** (need file access, commands, etc.) → Use Antigravity

---

## Credit Burn Warning Signs

🚨 Avoid these patterns in Antigravity:

- Long explanations you could get elsewhere
- "What is X?" questions (use free AI)
- Reading docs you could copy-paste
- Brainstorming sessions (no tools needed)

✅ **High-value patterns:**

- "Set up this project with X, Y, Z"
- "Refactor these 5 files to use new pattern"
- "Debug this + fix it + run tests"
- "Research best approach THEN implement it"
